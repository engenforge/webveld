3. Text-Level Elements

Hyperlink: anchor link (<a>).
Formatting: strong importance, stressed emphasis, alternate voice (i), stylistic offset (b), unarticulated annotation (u).
Code & Input: code snippet, kbd user input, sample output, variable x.
Semantics: HTML (abbr), Web Standards Manual (cite), inline quotation (q), marked highlight, small side-note, dfn defining instance, September 8, 2026 (time).
Vertical offset: Baseline text with subscript text and superscript text.
Edits: deleted text replaced with inserted text.
Flow control: Break opportunity here: supercalifragilistic, and an inline container: span element.
