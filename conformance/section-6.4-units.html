Section 6.4: Allowed Units Conformance Test

Exercises every unit permitted in Section 6.4 (absolute, relative, viewport) and calc() expressions.

1. Absolute Units (px, in, pt, cm, mm)

All 5 bars below are defined to equal exactly 192px (2 inches at 96 CSS dpi). In a conforming CSS engine, all 5 bars must have identical width matching the reference line:

192px (px - reference)
2in (in = 192px)
144pt (pt: 1pt = 4/3 px)
5.08cm (cm: 1in = 2.54cm)
50.8mm (mm: 1cm = 10mm)

2. Relative Units (em, rem, ex, ch, %)

Relative unit sizing against typography and containing block dimensions:

12em (relative to element font-size)
12rem (relative to root font-size)
24ex (relative to font x-height)
22ch (relative to monospace "0" width)
60% (relative to container width)

3. Viewport Units (vw, vh, vmin, vmax)

Viewport units dynamic sizing against the layout viewport:

35vw (35% of viewport width)
10vh (10% of viewport height)
25vmin (25% of smaller viewport dimension)
35vmax (35% of larger viewport dimension)

4. Mathematical calc() Function (+, -, *, /)

calc() calculations using basic arithmetic operators with allowed units:

calc(120px + 72px) = 192px (+)
calc(100% - 100px) (-)
calc(2.5rem * 4) = 10rem (*)
calc(384px / 2) = 192px (/)
